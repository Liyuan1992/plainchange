## Locked mental model

The overview is the permanent map. Details are a locally expanded layer of one overview step, not a replacement page or second graph.

## Desktop behavior

- Render the four overview steps as one top-to-bottom graph at all times.
- Clicking a closed overview step opens its mapped details immediately below that node and pushes later overview steps downward.
- Clicking the same overview step again collapses it.
- Clicking another overview step closes the previous group and opens the new one, keeping only one local expansion to limit cognitive load.
- Keep the right inspector visible and synchronized. With no group open it explains the selected overview; with a group open it explains the selected detail.
- Show `收起当前步骤` only while a group is open. It is a secondary convenience, not the primary navigation path.
- Preserve deep blue for current selection and amber for the source-bound current change. Both signals may coexist.

## Inline detail anatomy

- Begin with `这一步的详细过程` and the declared detail count.
- Use compact detail cards derived only from `detail_node_ids`.
- Show only declared direct relation labels between details; do not invent a sequential arrow when the source graph does not declare one.
- The expanded region uses a light blue surface and an inset boundary so it reads as belonging to its overview node.

## Narrow behavior

- Keep all overview steps in one column.
- Expand details within the same document flow and hide topology SVG links as before.
- Never require horizontal scrolling; labels and badges wrap below the main copy.

## Accessibility and controls

- Overview nodes remain buttons and expose expanded state with `aria-expanded`.
- Inline detail buttons expose selected state with `aria-pressed`.
- Escape and `收起当前步骤` collapse the open group.
- Focus returns to the overview node after collapse and moves to the first selected detail after expansion.

## Forbidden outcomes

- No overview node may disappear during expansion.
- No `返回四步总览` route or detail-only canvas.
- No target-name condition, invented step, invented connection, or claim-strength change.
