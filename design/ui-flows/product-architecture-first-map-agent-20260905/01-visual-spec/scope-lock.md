# Scope lock

- Existing and required: architecture tab, static-code groups, inspector, module drill-down, no-network single file, target-profile SHA binding. Preserve all.
- New but source-backed: profile-declared concept components and product/process relationships. Add only as a visibly profile-sourced layer.
- Existing but downplayed: source-code categories become the second layer; they must no longer be the first visual answer to “what is this system?”.
- Not allowed: fabricated live integrations, runtime arrows, user-impact claims, automatic approval, or a fake model call.
- Assets: no new asset is needed; CSS cards/arrows and text are sufficient.
