# Scope Lock

- In scope: optional software-control input, generic validation, two-screen HTML rendering, owner-language interactions, responsive behavior, tests, self-hosted artifact, and visual evidence.
- Preserve: current theme, renderer safety, all validated evidence, architecture implementation explorer, fallback UI, and target repository isolation.
- Exclude: model/provider calls, conversation capture, profile authoring, approval mutation, hosting, target-specific renderer rules, and unrelated refactors.
- Reference mode: agent.
- Maximum visual correction rounds: three.
- Round-2 owner correction: permit information-hierarchy and map-depth changes explicitly requested after the first production render; do not add persistent check state or infer four-step grouping inside the renderer.
