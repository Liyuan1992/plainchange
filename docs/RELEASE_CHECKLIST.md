# Alpha 发布检查清单

## 版本与治理

- [ ] 发布任务为 `DONE`，验收证据已写入任务记录。
- [ ] 版本号、CHANGELOG 和安装文档一致。
- [ ] 许可证与用户选择一致。
- [ ] 工作区只包含本次发布范围的改动。

## 安全与隐私

- [ ] 暂存内容不含 `.env`、本地模型配置、密钥、私有数据或生成报告。
- [ ] 引导服务只能监听本机。
- [ ] 跨来源请求、无会话令牌请求和任意文件读取均被拒绝。
- [ ] 目标仓库在端到端测试前后状态一致。

## 验证

- [ ] 完整 pytest 通过。
- [ ] Python 编译与两个浏览器脚本语法检查通过。
- [ ] wheel 与 sdist 构建成功，包内包含 HTML/CSS/JS。
- [ ] 新建隔离环境安装 wheel 后，`change-passport start --no-open` 可启动。
- [ ] 两提交样本可从浏览器接口生成并打开 `review.html`。
- [ ] 桌面与窄屏页面完成截图检查；控制台无错误。

## 交付

- [ ] `dist/SHA256SUMS.txt` 与实际包一致。
- [ ] 本地发布提交与带说明标签已创建。
- [ ] 没有 remote、push、部署或发布到公共包仓库。
- [ ] 对试用者明确说明 Alpha 的未知项和反馈方式。
