# Project governance

This directory holds the repository-owned process used by Codex, Claude Code, and human contributors.

- `PROJECT.md`: current project facts and commands.
- `WORKFLOW.md`: state machine, risk tiers, approvals, and closeout rules.
- `BUGLOG.md`: append-only source facts for every bug, including small ones.
- `EVOLUTION.md`: append-only source facts for material project changes and decisions.
- `domains/`: curated, domain-specific learning. This is the normal retrieval surface for future tasks.
- `decisions/`: Architecture Decision Records (ADRs).
- `tasks/`: bounded plans, evidence, and handoff records.
- `MAINTENANCE_QUEUE.md`: cursors and work for idle curation.

Raw logs are preserved but are not default task context. Curation converts their evidence into domain pages and links every derived claim back to source IDs.
