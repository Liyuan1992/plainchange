# ADR-0005: Separate the PlainChange brand from the Change Passport artifact

- Status: Accepted
- Date: 2026-09-10
- Decision owner: Project owner
- Related task: `TASK-20260910-038`

## Context

The original `Change Passport` name described the report well, but it constrained the whole product to one artifact and was not available as the public product identity. A mechanical global replacement would also break the meaning and traceability of existing `change-passport.*` evidence contracts.

## Decision

1. Use **PlainChange** for the product, repository, Python distribution, import package, CLI, cache, local web entry, and future public identity.
2. Keep **Change Passport** as the evidence-backed artifact generated by PlainChange and as the name of the existing report/protocol family.
3. Use `plainchange analyze .` as the explicit beginner CLI, `plainchange .` as its shorthand, and `plainchange serve` for the loopback web UI.
4. Lead public English copy with “Know what AI changed, what it affects, and what still needs verification.” Use “Without reading every changed line.” only as supporting copy.
5. Describe PlainChange as an AI change-understanding and human-control layer, not merely a Git diff summarizer.

## Consequences

- Existing `change-passport.*` schema identifiers remain stable and continue to describe the artifact contract.
- Old project-specific source paths are preserved only in historical evidence. Current imports, executable commands, profile paths, cache names, and UI branding use PlainChange.
- The local checkout folder may retain its historical name until an explicitly authorized repository move or remote publication; the distributable identity is `plainchange`.
- Public name availability, registry publication, remote creation, and trademark clearance remain separate release actions.

## Approval

Accepted through the owner's explicit brand architecture and CLI correction: PlainChange is the product, Change Passport is the core artifact, project analysis uses `plainchange analyze .`, and the web UI uses `plainchange serve`.
