# Curated domains

Create one page per bounded domain, such as `auth.md`, `memory.md`, or `desktop.md`. This is the normal task-time learning surface.

Each page separates active source-backed constraints, repeated patterns and regression checks, ADR links, open non-binding observations, and a source index. Every derived claim must cite BUG/EVO/ADR IDs. Raw logs remain the source of truth.
