# PlainChange 五问理解测试

状态：测试材料已准备；尚无独立非技术参与者结果。

找一位未参与目标项目开发、不会靠读源码作答的人。随机选择一份本轮
reviewed 报告，先看首屏 30 秒回答第 1 问，再允许浏览报告三分钟回答其余问题。
不要先教答案；允许回答“不知道”，记录原话、用时和实际点击位置。

1. 这个软件给谁用，解决什么具体问题？
2. 如果你要完成报告中的那件事，首先做什么，最后会拿到什么？
3. 过程中一个重要的分支或失败情况是什么，会发生什么？
4. 报告里哪件事情还不能确定？你会怎样核查？若没有保留问题，是否表示项目没有缺陷？
5. 找到支持一个解释或疑点的依据。能否分清项目自述、代码解读和实际运行验证？

每问按 0（错误或无法回答）、1（部分正确）、2（清楚且符合报告证据）记录。
建议验收门槛：至少 8/10，且不得把疑点说成已确认缺陷、把候选测试说成已通过，
或把“没有发现问题”理解为“系统没有问题”。这是待检验门槛，不是已取得的分数。
