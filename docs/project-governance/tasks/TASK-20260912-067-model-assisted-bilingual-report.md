# TASK-20260912-067：让模型报告真正支持中英文切换

状态：DONE
风险等级：标准
日期：2026-09-12
领域：模型语言合同、公开展示

## 用户问题

PlainChange 的 Git AI 自分析报告由模型生成中文负责人说明。切换到英文后，
导航、标签和固定界面文案已经变成英文，但模型生成的结论、验证说明、风险边界
和软件流程仍保留中文。页面却宣称 PlainChange 生成的解释已经是英文，形成了
直接可见的语言合同违约，也无法用于英文 README 截图。

## 目标

- 模型模式一次生成即可得到中英文两套、绑定同一报告身份的负责人说明。
- 第二语言只翻译展示文本，不改变证据 ID、证据状态、结构关系或验证结论。
- 英文译文中出现中文负责人正文时失败关闭；项目原话、代码标识和技术证据仍
  保留来源语言。
- 用 Git AI 自分析重新生成报告，作为中英文 README 和演示素材的真实来源。

## 非目标

- 不为 PlainChange、Git AI 或当前样本增加名称或内容特例。
- 不把翻译重新解释成新的事实判断。
- 不翻译代码路径、标识符、原始引文或证据载荷。
- 不提交、推送或发布版本。

## 实施计划

1. 增加受结构化输出约束的报告展示文本翻译阶段，并按稳定文本 ID 返回结果。
2. 从现有 `software-control` 与 `beginner-review` 的展示字段构造完整译文包，
   继续复用身份绑定和完整覆盖校验。
3. 模型分析完成后自动生成另一种受支持语言，并把阶段、耗时和安全遥测写入
   收据；离线 HTML 不在浏览时发起网络请求。
4. 增加中英文、混合语言拒绝、身份不变和模型管线回归测试。
5. 重跑 Git AI 自分析并检查两个 Tab 的可见语言，再更新双语 README 素材。

## 验收

- 中文生成的模型报告切换英文后，PlainChange 生成的结论、验证区和流程图均为
  英文；只有明确标注的来源原文、代码和证据可以保留中文。
- 英文生成的模型报告同时具备中文投影。
- 翻译缺项、重复 ID、未知 ID、空文本或英文译文含中文时失败关闭。
- 翻译不会改变 `control_identity`、`review_identity`、证据状态和证据引用。
- 完整测试、构建和静态语言检查通过。

## 批准依据

负责人已确认 README 与截图需要中英文最佳效果；在提供四张候选截图后明确指出
英文报告仍含中文。该修复是完成已批准公开展示工作的必要通用前置条件，不授权
提交、推送或发布。

## 实施结果

- 新增独立报告翻译阶段：按稳定文本 ID 分批翻译，不让模型重新解释事实；已经是
  目标语言的文本保持原样。
- 模型增强分析会在写入最终 HTML 前自动生成另一种受支持语言，并产出
  `report-translations.json` 与 `report-translation-run-receipt.json`。
- 译文继续复用既有 `control_identity`、`review_identity`、完整覆盖和字段白名单
  校验；缺项、重复/未知 ID、空文本或英文残留中文均会终止生成。
- README 中英文版已经把模型调用、双语离线报告和 Git AI 的互补关系改成当前
  真实行为；英文演示图片和 GIF 已替换为 v12 真实浏览器截图。
